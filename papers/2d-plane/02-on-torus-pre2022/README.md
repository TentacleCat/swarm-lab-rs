# Swarmalators on a Torus

---

## 1. Paper Reference
- **Topic**: Swarmalators confined on a 2D Torus $\mathbb{T}^2 = S^1 \times S^1$
- **Upstream Code**: [Khev/swarmalators/2D/on-torus](https://github.com/Khev/swarmalators/tree/master/2D/on-torus)

---

## 2. Model
Agents have periodic spatial coordinates $(x_i, y_i) \in [-\pi, \pi)^2$ and phases $\theta_i \in [-\pi, \pi)$.
Eliminates boundary confinement artifacts present in open $\mathbb{R}^2$ space, enabling pure topological analysis.
