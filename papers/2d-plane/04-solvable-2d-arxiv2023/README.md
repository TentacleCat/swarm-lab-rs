# A Solvable Two-Dimensional Swarmalator Model (arXiv 2023)

---

## 1. Paper Reference
- **Title**: A solvable two dimensional swarmalator model
- **Authors**: Kevin P. O'Keeffe et al.
- **arXiv**: [arXiv:2312.10178](https://arxiv.org/abs/2312.10178)

---

## 2. Key Contributions
- Formulates a 2D model with harmonic / pseudo-potential interactions that admits exact analytical solution in the continuum limit.
- Bridge between 1D Ott-Antonsen solvable models and realistic 2D swarming phenomena.
