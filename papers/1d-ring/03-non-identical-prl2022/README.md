## 2. Key Contributions
- Introduction of heterogeneous natural frequencies $\omega_i \sim g(\omega)$ and spatial drift velocities $\nu_i$.
- Exact analytical solvability via the Ott-Antonsen dimensional reduction technique for non-identical swarmalators.
- Transitions from coherence to incoherent turbulent swarming.
