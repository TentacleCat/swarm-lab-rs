## 1. Paper Reference
- **Title**: Swarmalators with delayed interactions

## 2. Key Contributions
- Introduces finite information propagation / interaction time delay $\tau > 0$ into the swarmalator dynamics.
- Time-delay induced instabilities and Hopf bifurcations.
